# Karibu JamboScript!

**JamboScript** ni lugha ya programu iliyoundwa kwa Kiswahili. Inabadilika kuwa JavaScript.

## Mfano wa Haraka

```javascript
kazi salamu(jina) {
  kama (jina ni "Fatma") {
    andika("Jambo boss 👑")
  } la sivyo {
    andika("Jambo " + jina)
  }
}

salamu("Fatma")
salamu("Juma")
```

## Kusakinisha

```bash
npm install -g jamboscript
```

## Programu Yako ya Kwanza

Tengeneza faili inayoitwa `habari.jambo`:

```javascript
andika("Habari Dunia!")

acha jina = "Juma"
andika("Jina langu ni " + jina)
```

Iendeshe:

```bash
jamboscript habari.jambo
```

## Kwa Nini JamboScript?

- **Jifunze kwa Kiswahili** — Tumia maneno unayoyajua kama `kazi`, `kama`, `andika`
- **JavaScript Halisi** — Inabadilika kuwa JS safi unayoweza kutumia popote
- **Kamilifu** — Vibadilika, kazi, mizunguko, masharti, na zaidi
