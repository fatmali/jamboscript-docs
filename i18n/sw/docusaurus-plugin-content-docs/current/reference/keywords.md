# Rejea ya Maneno Yote

Rejea kamili ya maneno yote ya JamboScript.

## Vibadilika

| JamboScript | JavaScript | Maana |
|-------------|------------|-------|
| `acha` | `let` | acha/ruhusu |
| `thabiti` | `const` | thabiti |

## Kazi

| JamboScript | JavaScript | Maana |
|-------------|------------|-------|
| `kazi` | `function` | kazi |
| `rudisha` | `return` | rudisha |
| `andika` | `console.log` | chapisha |

## Udhibiti wa Mtiririko

| JamboScript | JavaScript | Maana |
|-------------|------------|-------|
| `kama` | `if` | kama |
| `la sivyo` | `else` | la sivyo |

## Mizunguko

| JamboScript | JavaScript | Maana |
|-------------|------------|-------|
| `wakati` | `while` | wakati |
| `rudia` | `for` | rudia |
| `vunja` | `break` | vunja |

## Chagua

| JamboScript | JavaScript | Maana |
|-------------|------------|-------|
| `chagua` | `switch` | chagua |
