# Keyword Reference

Complete reference of all JamboScript keywords.

## Variables

| JamboScript | JavaScript | Meaning |
|-------------|------------|---------|
| `acha` | `let` | let/allow |
| `thabiti` | `const` | constant |

## Functions

| JamboScript | JavaScript | Meaning |
|-------------|------------|---------|
| `kazi` | `function` | function |
| `rudisha` | `return` | return |
| `andika` | `console.log` | print |

## Control Flow

| JamboScript | JavaScript | Meaning |
|-------------|------------|---------|
| `kama` | `if` | if |
| `la sivyo` | `else` | else |

## Loops

| JamboScript | JavaScript | Meaning |
|-------------|------------|---------|
| `wakati` | `while` | while |
| `rudia` | `for` | for/repeat |
| `vunja` | `break` | break |
| `endelea` | `continue` | continue |

## Switch

| JamboScript | JavaScript | Meaning |
|-------------|------------|---------|
| `chagua` | `switch` | switch |
| `hali` | `case` | case |
| `kawaida` | `default` | default |

## Booleans & Null

| JamboScript | JavaScript | Meaning |
|-------------|------------|---------|
| `kweli` | `true` | true |
| `sivyo` | `false` | false |
| `tupu` | `null` | null |

## Comparison Operators

| JamboScript | Symbol | Meaning |
|-------------|--------|---------|
| `ni` | `==` | equals |
| `chini` | `<` | less than |
| `zaidi` | `>` | greater than |
| `mpaka` | `<=` | less or equal |
| `angalau` | `>=` | greater or equal |

## Logical Operators

| JamboScript | Symbol | Meaning |
|-------------|--------|---------|
| `na` | `&&` | and |
| `au` | `\|\|` | or |
| `si` | `!` | not |

## Arithmetic

| Symbol | Meaning |
|--------|---------|
| `+` | add |
| `-` | subtract |
| `*` | multiply |
| `/` | divide |
| `%` | modulo |
| `++` | increment |
| `--` | decrement |

## Assignment

| Symbol | Meaning |
|--------|---------|
| `=` | assign |
| `+=` | add and assign |
| `-=` | subtract and assign |
| `*=` | multiply and assign |
| `/=` | divide and assign |
